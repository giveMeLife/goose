# Session `/usage` Command Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `/usage`, a colorized interactive report of current session-tree usage, cost by model/provider, and last-response performance.

**Architecture:** Extend the persisted usage ledger query with a public grouped usage summary that walks the root session and subagent descendants. `CliSession` retains last-turn timing/usage locally, dispatches a new parsed command, and passes totals/grouped rows to pure output formatters that apply the established terminal palette.

**Tech Stack:** Rust, SQLite/sqlx, Goose `SessionManager`, `console` styles, existing `ProviderUsage` metrics.

**Spec:** `docs/superpowers/specs/2026-09-09-session-usage-command-design.md`

## Global Constraints

- `/usage` has no arguments and uses normal line output; no cursor-control dashboard.
- Totals and groups include root plus all descendant subagent sessions.
- Every group label is `model / provider`; sort known cost descending, then total tokens descending.
- Unknown cost displays as `unknown` without a percentage but token-known groups remain visible.
- TTFT/TPS reflect only the last response generated by the current CLI process; resumed sessions show unavailable until that occurs.
- Preserve JSON and stream-JSON output modes; slash command affects only interactive text sessions.
